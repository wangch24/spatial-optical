# 光子智能课题组 · 空间光计算与感知

为课题组研究方向制作的静态学术主页，包含独立的 Resources 资料链接页。无需安装依赖或执行构建。

## 立即开始

1. 完整解压后双击 `index.html` 预览网站。
2. 双击 `START_HERE.html` 阅读详细部署与更新教程，或查看 [Markdown 教程](DEPLOY_GUIDE.md)。
3. 把本目录的内容上传到 GitHub 仓库根目录。
4. Settings → Pages → Deploy from a branch → main → /(root) → Save。
5. 日常更新主要修改 `assets/site-data.js`。

## 页面与资料

- `index.html`：课题组介绍、研究方向、预留研究成果。
- `resources.html`：技术文档链接、搜索和分类。
- 默认资料为标明来源的公开参考文档；请自行补充课题组内容。
- 文档访问权限由原文档平台管理，网站本身不提供登录或上传后台。
- 所有资源使用相对路径，兼容 `username.github.io` 及 `username.github.io/repo/`。
